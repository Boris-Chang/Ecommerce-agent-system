# Shopify Product Page Optimization Skill

## Goal

Generate a conversion-focused Shopify product page draft based on the current product data.

The output should help a store operator manually review and improve the product page. Do not claim that changes have been applied to Shopify.

## Product Title Framework

A strong product title should include:

1. Core product keyword
2. Main use case or target scenario
3. Key benefit or differentiator

Avoid vague titles, keyword stuffing, exaggerated claims, or unsupported medical/safety claims.

## Hero Selling Points

Hero bullets should be short, specific, and benefit-driven.

Each bullet should answer one of these questions:

- What problem does this product solve?
- What user scenario is it useful for?
- What feature creates the benefit?
- Why should the buyer trust or consider it?

## Product Description Structure

Use this structure:

1. Pain point or use scenario
2. Product solution
3. Key benefits
4. Feature explanation
5. Usage scenarios
6. Specifications
7. FAQ
8. Trust or purchase reassurance

## SEO Title

SEO title should include:

- Core product keyword
- Main benefit
- Use case if appropriate

Avoid being too long or too generic.

## SEO Description

SEO description should clearly explain:

- What the product is
- Who it is for
- Main benefit
- Why it is useful

## FAQ

FAQ should cover:

- Product usage
- Size or compatibility
- Material or care
- Shipping or setup concerns if relevant
- Common buyer objections

## Output Style

Use clear ecommerce copy.
Prefer concrete benefits over abstract claims.
Keep language natural and suitable for a DTC Shopify product page.
